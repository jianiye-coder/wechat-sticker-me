# 用户可选模板

当用户想选模板、尚未确定风格，或希望快速开始时，先展示以下精简菜单。用户已经说明方向就直接匹配，不强迫再选。模板是组合起点，不是只有这些选择。

| 模板 | 画风与语气 | 常用表情举例 |
|---|---|---|
| 软萌日常 | 大头小身，温柔亲切 | 开心、收到、抱抱、谢谢 |
| 情绪小剧场 | 夸张漫画，动作有戏 | 震惊、偷笑、抓狂、吃瓜 |
| 冷脸吐槽 | 极简扁平，冷幽默 | 行吧、就这、无语、不想动 |
| 打工日常 | Q版，礼貌中带疲惫 | 在忙、稍等、改好了、下班 |
| 甜甜陪伴 | 软萌Q版，亲昵 | 想你、贴贴、等你、哄我 |
| 手帐慢生活 | 手绘涂鸦，松弛温暖 | 喝茶、晒太阳、散步去、歇一会 |
| 黏土小情绪 | 圆润立体黏土，夸张可爱 | 得意、救命、累瘫、撒娇 |
| 像素日常 | 复古像素，简短回应 | 开心、等等、加油、溜了 |

每个模板的16项动作和文案、3张试稿、候选专辑名、简介、封面与横幅方向统一维护在 [templates/catalog.json](../templates/catalog.json)。这是文字配方，不含已生成参考图，不能称为成品视觉模板或已过审范本。用户想看视觉效果时用当前图像工具做试稿，不拿别人的角色假装用户成品。

## 选择与混搭

- 推荐时结合用途精选3项；用户要求全部模板再展示8项。给用户一个容易回答的选择：“选一种，或说‘冷脸画风＋打工文案’。”不要连续问配色、字体、数量等一长串问题。
- 画风和场景可独立搭配。例：黏土＋打工、像素＋吐槽、Q版＋慢生活。混搭后以同一角色锁定画风，不在同一套中随机切换材质。
- 照片里的外貌和服装优先于模板，不默认作者姓名、性别、发型、肤色。亲昵模板仅在用户选择或关系用途明确时采用，不凭照片猜关系。
- 模板文案可自由替换，候选名称未查重；表情数量依用户意图和当前投稿页调整。不要未经认可补图凑数或自动删除用户指定保留图。
- 试稿词不必出现在最终选题中：用开心、生气、疑惑测试角色后，保留模板自身选题。试稿阶段未获认可时不批量生成。

## 工具用法

```
python scripts/choose_template.py
python scripts/choose_template.py drama-club --out work/brief.json
python scripts/choose_template.py office-life --style clay --title "今天也要下班" --out work/brief-clay.json
```

`choose_template.py` 只产生创意草案，不生成图片、不上传、不填写假source路径。下一步结合用户照片补充人物约束，生成试稿和单图；最终创建具有实际源图路径的build清单。已有文件不覆盖，换版本名。模板选择和用户修改记录在项目，不能把用户自定义回写共享模板库。
